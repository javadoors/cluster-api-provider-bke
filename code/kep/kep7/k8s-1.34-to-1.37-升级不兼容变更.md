# Kubernetes 1.34 → 1.37 不兼容变更与升级指南

> 数据来源：
> - 官方 API 弃用指南 https://kubernetes.io/docs/reference/using-api/deprecation-guide/
> - 各版本 CHANGELOG 中的 `Urgent Upgrade Notes` / `Deprecation` / `API Change` 章节
> - 版本偏差策略 https://kubernetes.io/releases/version-skew-policy/

> 说明：官方弃用指南中“按版本移除的 API”目前最新只到 v1.32（flowcontrol v1beta3），因此 1.34–1.37 期间**没有**内置资源组版本的批量移除。此窗口内的变更主要集中在 feature-gate 收紧、Flags/字段移除、指标重命名、默认行为改变，以及 alpha/beta API 迁移（DRA、Workload/PodGroup、StorageVersionMigration、PodCertificate 等）。

## 摘要（总结性不兼容变更）

### 1. 组件启动失败类（升级前必须清理 Flags）
- kubelet：`--cloud-config`（1.34）、`--register-schedulable`（1.34）、`--pod-infra-container-image`（1.35）。
- kubelet 内嵌 cAdvisor：一批已弃用 cAdvisor Flags 被移除，设置任一即启动失败（1.37）。
- 节点运行环境：cgroup v1 被弃用，`failCgroupV1` 默认 true（1.35）。

### 2. API 对象移除（升级前必须删除对应资源）
- DRA：`resource.k8s.io/v1alpha3`（仅留 DeviceTaintRule）、kubelet gRPC `v1alpha4`、`admin-access` 标签改名（1.34）。
- `StorageVersionMigration v1alpha1`（1.35）。
- `scheduling.k8s.io` Workload/PodGroup：`v1alpha1` 移除（1.36）→ `v1alpha2` 移除（1.37）。
- `SnapshotMetadataService v1alpha1`（1.36）。
- PodCertificateRequest：`PKIXPublicKey`/`ProofOfPossession` 字段移除（1.37）。

### 3. 依赖第三方集成改造
- 客户端：gogo/protobuf 移除（1.34 起）、REST client API streaming 移除（1.34）。
- Scheduler 插件：PreFilter 接收 NodeInfo（1.34）、PreBind 返回 `PreBindPreFlightResult`（1.36）。
- DRA driver：细粒度 RBAC 权限（1.36）。

### 4. 指标重命名 / 标签拆解（影响监控告警）
- 大量 apiserver/etcd 指标 label 拆分为 `group`+`resource`（1.34）。
- `scheduler_scheduler_cache_size`、`apiserver_encryption_config_controller_automatic_reload_*`（1.34）。
- `etcd_bookmark_counts`→`etcd_bookmark_total`、`volume_operation_total_errors`→`volume_operation_errors_total`（1.36）。

### 5. 默认行为改变（高风险）
- `SELinuxMount` GA（1.37，SELinux 集群可能破坏工作负载）。
- kubelet `eventRecordQPS=0` 变为不限流（1.37）。
- kube-proxy 向 nftables 过渡，`ipvs` 弃用（1.35/1.37）。
- kubeadm 移除 flex-volumes 内置支持（1.36）。
- `git-repo` volume 插件禁用（1.36）。

## 一、v1.34（从 1.33 升级）

### 必须处理（会直接导致失败/行为改变）

- **kubelet 移除 `--cloud-config` 标志**：配置了该标志会导致启动失败。
- **kubelet 移除 `--register-schedulable` 标志**。
- **移除 `LegacySidecarContainers` feature gate**（彻底移除）。
- **移除 `DevicePluginCDIDevices`、`PodDisruptionConditions` 等已 GA 的 feature gate**。
- **DRA API 迁移/清理**：
  - 删除 kubelet gRPC `v1alpha4` API（DRA driver 应使用 v1beta1 helper）。
  - `resource.k8s.io/v1alpha3` 仅保留 `DeviceTaintRule`，其余类型移除；升级前需删除 `<1.32` 存储的 resourceclaims / resourceclaimtemplates / deviceclasses / resourceslices 对象。
  - `admin-access` 标签由 `resource.k8s.io/admin-access` 改为 `resource.kubernetes.io/admin-access`。
- **移除 gogo/protobuf**：`cri-api`、`kubelet/pkg/apis/deviceplugin`、`podresources`、`kms/apis`、`externaljwt`、`pluginregistration` 等包中已弃用的 gogo 协议定义被移除。
- **移除 REST 客户端 API streaming**：typed / dynamic / metadata client 的 `List()` streaming 支持，以及 `kubernetes.io/initial-events-list-blueprint` 注解。
- **指标重命名与标签拆解**：
  - `apiserver_encryption_config_controller_automatic_reload_success_total` / `_failure_total` → `apiserver_encryption_config_controller_automatic_reloads_total`。
  - `scheduler_scheduler_cache_size` → `scheduler_cache_size`。
  - apiserver/etcd 大量指标 label 由 `resource`/`type`/`kind` 拆为 `group` + `resource`（见 CHANGELOG #131845）。

### 弃用

- kubeconfig `preferences` 字段弃用，改用 `kuberc`。
- DRA kubelet gRPC 毕业到 v1，v1beta1 弃用。

## 二、v1.35（从 1.34 升级）

### 必须处理

- **kubelet 移除 `--pod-infra-container-image` 标志**：
  - 非 kubeadm 集群需先从 kubelet 配置中删除，否则启动失败。
  - kubeadm 集群若在 `extraArgs` 中传入，需手动删除（init/join 不会自动清理）。
- **cgroup v1 弃用（`failCgroupV1` 默认 true）**：
  - kubelet ≥1.35 在 cgroup v1 主机上默认无法启动。
  - kubeadm preflight 对 cgroup v1 直接报错（SystemVerification）；可通过 `failCgroupV1: false` 或忽略 preflight 规避。
- **kube-proxy `ipvs` 模式弃用**：建议迁移 nftables（新内核）/ iptables（旧内核）。
- **`StorageVersionMigration` 移除 `v1alpha1`，仅保留 `v1beta1`**：升级前必须删除所有 v1alpha1 对象。
- **移除 `StrictCostEnforcementForVAP`、`StrictCostEnforcementForWebhooks` feature gate**（自 v1.32 起已锁定）。
- **Go API 类型移除 gogo/protobuf**：不再默认实现 `ProtoMessage()`。可用构建标签 `kubernetes_protomessage_one_more_release` 暂缓一个版本，但 1.36 起彻底移除。
- **Pod resize 仅允许 CPU/内存**，其他资源类型被禁止。
- **`Partitionable Devices`（alpha）向后不兼容**：1.34↔1.35 之间升级/降级前需删除使用该特性的 ResourceSlice。
- **Service `trafficDistribution=PreferClose` 弃用**，改用 `PreferSameZone`。

## 三、v1.36（从 1.35 升级）

### 必须处理（ACTION REQUIRED）

- **kubeadm 移除对 flex-volumes 的内置支持**：
  - 继续使用需自定义非 distroless 的 KCM 镜像，传 `--flex-volume-plugin-dir`，并用 `extraVolumes` 挂载 `/usr/libexec/kubernetes/kubelet-plugins/volume/exec`。
  - 升级前若不处理，该功能失效。
- **DRA 细粒度 RBAC（`DRAResourceClaimGranularStatusAuthorization` beta 默认开启）**：
  - scheduler / controller 需要 `resourceclaims/binding` 的 update/patch 权限。
  - DRA driver 需要 `resourceclaims/driver` 的 `associated-node:update` 或 `arbitrary-node:update`（或 patch 等价），并按具体 `resourceNames` 限制。
- **指标重命名**：
  - `etcd_bookmark_counts` → `etcd_bookmark_total`。
  - `volume_operation_total_errors` → `volume_operation_errors_total`。
  - 需同步更新自定义监控大盘与告警规则。
- **Scheduler PreBind 插件并行化**：插件需将 `PreBindPreFlight` 改为返回 `PreBindPreFlightResult`；返回 nil 保持串行行为。

### API 移除 / 弃用

- **`scheduling.k8s.io/v1alpha1` Workload API 移除**，替换为 `v1alpha2`。
- **`SnapshotMetadataService` 移除 `v1alpha1`，升 `v1beta1`**。
- **gogo `ProtoMessage` 构建标签彻底删除**。
- **Service `.spec.externalIPs` 弃用告警**。
- **`git-repo` volume 插件默认禁用且无法再开启**。
- **`metav1.FieldsV1.Raw` 直读弃用**，改用 `NewFieldsV1` / `GetRawBytes` / `GetRawString` / `SetRawBytes`。
- **Pod Certificates**：`pkixPublicKey` / `proofOfPossession` 弃用，改用 `stubPKCS10Request`。
- `sets.String` → `sets.Set[string]`：对 `NewLifecycle` 函数消费者是 breaking change。

## 四、v1.37（从 1.36 升级）

### 必须处理（ACTION REQUIRED）

- **`SELinuxMount` 毕业 GA（默认开启）**：
  - 对启用 SELinux 的集群可能破坏现有工作负载。
  - 升级前按官方博客排查/修复，或选择退出：https://kubernetes.io/blog/2026/04/22/breaking-changes-in-selinux-volume-labeling/
  - 未启用 SELinux 的集群可忽略。
- **`DisruptionMode` 由枚举改为结构体；`scheduling.k8s.io` 从 `v1alpha2` 升 `v1alpha3` 并彻底丢弃 `v1alpha2`**：
  - 升级前必须删除所有 v1alpha2 对象。
- **kubelet `eventRecordQPS=0` 现表示不限流**（与文档对齐）：
  - 依赖旧默认限流行为者需显式设置非 0 值（例如 50）。
- **kubelet 默认记录生效配置到日志**：需限制 `nodes/logs` ClusterRole 仅授予可信用户。

### API 移除 / 弃用 / 行为变化

- **PodCertificateRequest 毕业 GA**：`PKIXPublicKey`、`ProofOfPossession` 字段从 v1 API 移除，升级前更新客户端。
- **kubelet 内嵌 cAdvisor 切换为精简模块（`github.com/google/cadvisor/lib`）**：
  - 一批已弃用 cAdvisor Flags 被移除，设置任一导致 kubelet 启动失败（仅保留 `--housekeeping-interval`）：`--application-metrics-count-limit`、`--boot-id-file`、`--container-hints`、`--containerd`、`--containerd-namespace`、`--enable-load-reader`、`--event-storage-age-limit`、`--event-storage-event-limit`、`--global-housekeeping-interval`、`--log-cadvisor-usage`、`--machine-id-file`、`--storage-driver-*` 系列。
  - `userDefinedMetrics` 及 `container_cpu_load_average_10s`、`container_cpu_load_d_average_10s`、`container_tasks_state` 等指标不再导出。
- **kube-proxy 向 nftables 过渡**：
  - kubeadm 在未提供 `KubeProxyConfiguration` 或 mode 为空时显式设为 iptables。
  - 未显式设置 mode 会有告警；ipvs 自 v1.35 起弃用。
- `kubectl run -f/--filename` 弃用（此前即被忽略）。
- `DeclarativeValidationTakeover` feature gate 锁定为默认值，不可再设置。
- `NodeSyncPeriod` 从 `KubeCloudSharedConfiguration` 迁移至 `CloudControllerManagerConfiguration.NodeLifecycleController.NodeMonitorPeriod`。
- 默认 etcd 升到 `v3.7.0`；grpc 升 `v1.82.1`（移除 `GRPC_GO_EXPERIMENTAL_DISABLE_STRICT_PATH_CHECKING`）；构建使用 Go 1.26。

## 五、升级实施建议

### 1. 组件升级顺序（官方 version-skew）

1. **kube-apiserver**（HA 集群新旧版本间最多相差 1 个小版本；不允许跳小版本）。
2. **kube-controller-manager / kube-scheduler / cloud-controller-manager**（不得新于 apiserver，可滞后 1 个小版本）。
3. **kubelet**（逐节点 drain；不得新于 apiserver，可滞后 3 个小版本）。
4. **kube-proxy**（不得新于 apiserver，可滞后 3 个小版本）。

### 2. 升级前清单

- [ ] 清理被移除 API 的对象：DRA v1alpha3/v1alpha4、StorageVersionMigration v1alpha1、Workload/PodGroup v1alpha1→v1alpha2→v1alpha3、SnapshotMetadataService v1alpha1（逐级清理）。
- [ ] 清理 kubelet Flags：`--cloud-config`、`--register-schedulable`、`--pod-infra-container-image`、cAdvisor 已弃用 Flags。
- [ ] 处理第三方集成：scheduler 插件（PreBind/PreFilter）、DRA driver RBAC、客户端移除 gogo/protobuf 与 streaming。
- [ ] 更新监控/告警：重命名指标（etcd_bookmark、volume_operation、scheduler_cache_size、automatic_reload 系列）及 apiserver/etcd 标签拆解。
- [ ] 特殊环境单独评估：cgroup v1、SELinux、kube-proxy ipvs、flex-volume。

### 3. 迁移工具

- 使用 `kubectl convert -f <file> --output-version <group>/<version>` 自动转换旧对象（需单独安装 `kubectl-convert` 插件）。
- 升级前可用 `--runtime-config=<group>/<version>=false` 模拟禁用将被移除的 API，验证兼容性。
